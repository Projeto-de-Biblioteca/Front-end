# Biblioteca Digital - Front-end (PWA)

Este repositório contém a interface da aplicação de gerenciamento de acervo pessoal. O projeto foi desenvolvido como um **PWA (Progressive Web App)**, permitindo a instalação em dispositivos móveis.

## Tecnologias Utilizadas
* **HTML5 / CSS3 / JavaScript**
* **Bootstrap 5**: Para o layout responsivo.
* **Lucide Icons**: Para a iconografia do sistema.
* **PWA**: Suporte a Service Workers e Manifest para instalação local.

## Como rodar o projeto
1. Clone este repositório.
2. Abra o arquivo `index.html` em seu navegador ou utilize a extensão **Live Server** do VS Code.
